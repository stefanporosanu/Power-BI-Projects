## 🔎 Overview

This repository contains a **Microsoft Power BI project** completed during my Data Technician Bootcamp.

The project demonstrates practical experience importing and transforming data, building a structured data model, creating measures and developing **interactive reports to analyse sales, profitability and performance against targets**.

The finished report contains three key pages:

- 📊 **Overview**
- 💰 **Profit**
- 🎯 **My Performance**

Together, these pages provide different views of business performance and allow users to explore the data interactively using filters and slicers.

## 📊 Report Structure

### 📈 Overview

The **Overview** page provides a high-level view of business performance.

It includes analysis of:

- Sales over time
- Profit margin
- Sales by country
- Sales by product category
- Quantity sold by product category
- Regional performance

Interactive **Year** and **Region** slicers allow users to explore performance across different periods and locations.

Visualisations include:

- 📊 Column charts
- 📈 Combination charts
- 📉 Bar charts
- 🎛️ Interactive slicers

---

## 🌍 Sales by Region & Product

Sales data was analysed across different countries and product categories to identify where revenue was being generated.

This included:

- Comparing sales between countries
- Breaking sales down by product category
- Analysing quantities sold
- Filtering performance by region
- Identifying differences between markets

These visualisations help convert detailed sales records into clear comparisons that can support business decisions.

---

## 💰 Profit Analysis

The **Profit** page focuses on financial performance and provides a structured view of key business measures.

Metrics analysed include:

| Metric | Purpose |
|---|---|
| 💷 **Sales** | Total sales generated |
| 🧾 **Orders** | Number of customer orders |
| 💸 **Cost** | Total cost associated with sales |
| 📈 **Profit** | Financial return after costs |
| 📊 **Profit Margin** | Profitability relative to sales |

A region slicer allows the financial results to be analysed for different areas.

The report uses a matrix-style visual to compare performance across fiscal years.

---

## 🎯 Performance vs. Target

The **My Performance** page compares actual business performance against predefined targets.

Key metrics include:

- **Sales**
- **Target**
- **Variance**
- **Variance Margin**

These measures make it possible to quickly understand whether performance is above or below target.

The page also includes monthly visualisations comparing:

**Actual Sales vs. Target**

This demonstrates how Power BI can be used for **performance monitoring and management reporting**, rather than simply displaying historical data.

## 🧮 DAX & Calculated Measures

DAX measures were used to extend the underlying data model and create business-focused calculations.

Measures used within the project include:

```text
Orders
Profit
Profit Margin
Target
Variance
Variance Margin
```

These measures support more meaningful analysis than relying only on raw columns and allow calculations to respond dynamically to report filters.

## 🎨 Data Storytelling

A key focus of the project was presenting business information in a way that makes performance easy to understand.

Rather than displaying isolated charts, the report combines related metrics to answer practical questions such as:

- How are sales changing over time?
- Which countries and product categories generate the most sales?
- How profitable is the business?
- How does actual performance compare with target?
- Which regions are performing differently?
- Where are the largest positive or negative variances?

This approach demonstrates how Power BI can turn raw business data into **clear, interactive and decision-focused reporting**.
